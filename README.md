# Elderlymonitoringsystem




Project Overview

The Elderly Monitoring System is a smart web and mobile-based application developed to monitor and support elderly individuals using modern technology.

With the increasing number of elderly people living alone, issues such as delayed medical assistance, missed medications, and lack of continuous monitoring have become serious concerns. Traditional caregiving methods may not always provide real-time support and safety.

This project focuses on developing a system that helps caregivers and family members monitor elderly patients efficiently through digital technology, ensuring timely care and improved safety.



Objective

The main objective of this project is to:

* Provide continuous monitoring for elderly individuals
* Ensure timely medication through reminders
* Enable quick emergency response (fall detection alerts)
* Reduce dependency on manual caregiving
* Maintain digital records of patients and caretakers
* Improve communication between users and caretakers


Features Implemented

 1️⃣ User (Patient) Management

* Register and manage elderly users
* Store personal and medical details
* View and update user profile

 2️⃣ Caretaker Management

* Add and manage caretaker details
* Assign caretakers to patients
* Track caretaker activities

 3️⃣ Patient Monitoring

* Store patient health details
* Track current condition and medical history
* Enable continuous monitoring

 4️⃣ Pill Reminder System

* Schedule medication timings
* Notify patients to take medicines
* Maintain reminder records

 5️⃣ Fall Detection & Alert System

* Detect fall events
* Send alerts to caretakers and family members
* Store fall notification details

 6️⃣ Request & Assignment System

* Users can request caretaker services
* Admin assigns caretakers
* Track request status

 7️⃣ Complaint & Review System

* Users can submit complaints
* Provide feedback and ratings for caretakers

8️⃣ Payment Management

* Maintain caretaker payment records
* Track payment status



Technologies Used

Frontend: HTML, CSS, JavaScript / Flutter (if mobile app)
Backend: Django (Python)
Database: SQLite / MySQL
Notifications: API-based alerts
System Type: Web + Mobile Integrated System



System Workflow

 User registers and logs into the system
 Patient details are stored in the database
 User requests a caretaker if needed
 Admin assigns a caretaker to the patient
 Caretaker monitors the patient and updates status
 Pill reminders notify patients at scheduled times
 If a fall is detected → alert is sent immediately
 All activities (requests, alerts, payments) are stored in the database

The Elderly Monitoring System provides a smart and reliable solution for elderly care by integrating monitoring, alert systems, and digital management. It enhances safety, ensures timely medical support, and improves the quality of life for elderly individuals while reducing the burden on caregivers.
